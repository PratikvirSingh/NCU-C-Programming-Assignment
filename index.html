From local code to live link.

The assignment portal asks for a website URL and states that submission must be made through a specified public GitHub repository. Use the checklist below before submitting.

01

Review & test

Open each solution, compile with a C11 compiler, and compare its output with the sample. Read the platform's original statement for any input-format differences.

02

Create public repo

On GitHub, create a public repository for this assignment. Upload the contents of this project folder, not the ZIP file itself.

03

Enable Pages

Open Settings → Pages. Select Deploy from a branch, choose main and /(root), then Save. Wait for the deployment URL.

04

Submit on NCU

Open the live Pages URL, check it on desktop and phone, then paste that URL into the assignment's website URL submission field.
